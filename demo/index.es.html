img-previewer

A lightweight, dependency-free image viewer. Click a photo and it grows from where it sits to the center of the screen, then flies back when you close it.

npm i img-previewer

Click any photo to open it

Controls Install Usage Options Methods

Controls

Once a photo is open you can use these. On touch screens, pinch to zoom.

  • ZoomMouse wheel or + -
  • PanDrag after zooming in
  • Previous / next← →
  • CloseEsc or click the backdrop
  • Rotate, zoom and resetToolbar, top right

Install

npm i img-previewer
# or
pnpm add img-previewer

Or load it from a CDN:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/img-previewer/dist/index.css">
<script src="https://cdn.jsdelivr.net/npm/img-previewer/dist/img-previewer.min.js"></script>

Usage

Pass a CSS selector. Every <img> inside it opens on click, with no changes to your existing HTML.

import ImgPreviewer from 'img-previewer'
import 'img-previewer/dist/index.css'

const previewer = new ImgPreviewer('#app', {
  fillRatio: 0.8,
  onShow() {},
  onHide() {}
})

Adding images later? Call previewer.update() after they render.
